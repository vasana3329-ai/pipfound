# pipfound

**تحلیل‌گرِ اسمارت‌مانی (SMC/ICT) به‌شکلِ یک وب‌اپِ نصب‌شدنی (PWA) که کاملاً روی دستگاهِ خودت اجرا می‌شود.**
دیتای واقعیِ بازار، **بدونِ کلیدِ API**، **بدونِ وابستگیِ بیرونی** (فقط کتابخانهٔ استانداردِ پایتون) و **فقط روی `127.0.0.1`**.

[![pipfound health guard](https://github.com/vasana3329-ai/pipfound/actions/workflows/selfcheck.yml/badge.svg)](https://github.com/vasana3329-ai/pipfound/actions/workflows/selfcheck.yml)

رابطِ کاربری، پیام‌ها و خروجیِ تحلیل **کاملاً فارسی** است.

---

## این اپ چه می‌کند

- **موتورِ SMC/ICT روی کندل‌های واقعی:** سوینگ‌ها، ساختار (BOS / CHoCH / MSS)، فیرولیوگپ (FVG)، اُردربلاک (OB)، لیکوئیدیتی و EQH/EQL، سوئیپ، دیسپلیسمنت، پریمیوم/دیسکانت، OTE و الگوهای کندلی.
- **گریـدرِ هم‌رایی (Confluence Gridder):** همه‌ی لایه‌ها روی هم وزن می‌گیرند و یک **درجه** (A+ … C) با دلایلِ فارسی می‌سازند.
- **پلنِ معامله:** جهت، ناحیهٔ ورود، حدِ ضرر، حدِ سود، R:R، و **مهرِ تأییدِ ورود** (فقط با شروطِ سخت‌گیرانه).
- **صداقتِ داده:** تحلیل فقط روی **کندلِ بسته** انجام می‌شود؛ کندلِ در حالِ تشکیل هرگز سیگنال نمی‌سازد. اگر بازار بسته یا داده کهنه باشد، درجه سقف می‌خورد و پلن «الان قابلِ اجرا نیست» علامت می‌گیرد.
- **مدیریتِ ریسک:** سایزِ پوزیشن (لات/کانترکت/سهم/واحد) از سرمایه و درصدِ ریسک، سقفِ ضررِ روزانه، سقفِ ریسکِ باز، و هشدارِ **تمرکز/هم‌بستگی** — از جمله جدولِ ضرایبِ مرجعِ بازار (طلا↔دلار منفی، طلا↔دلارِ کانادا مثبت، BTC↔ETH مثبت، …) با تذکرِ عددی در لحظهٔ ثبتِ معامله.
- **واگراییِ SMT** بین جفت‌های هم‌بسته، **دیورجنس** و هشدارِ تریدِ خلافِ جهت.
- **ژورنالِ معاملات، آلارم‌های قیمتی، بک‌تست، تقویمِ اخبارِ اقتصادی، و متراکم‌سازیِ تایم‌فریم.**
- **انتقالِ داده:** برون‌بری/درون‌بریِ کلِ دادهٔ کاربر (ژورنال، آلارم‌ها، تنظیمات) به JSON + **پشتیبانِ خودکارِ زمان‌بندی‌شده** با نگه‌داشتِ چند نسخهٔ اخیر.

## اجرا

نیازها: **پایتون ۳٫۱۱+** (فقط کتابخانهٔ استاندارد؛ `certifi` اختیاری است). نود فقط برای چکِ سینتکسِ جاوااسکریپت و تستِ مرورگری لازم می‌شود.

```bash
python3 app.py                 # → http://127.0.0.1:8787
python3 app.py --port 9000     # پورتِ دلخواه
python3 app.py --no-autorestart
```

سپس در مرورگر `http://127.0.0.1:8787` را باز کن. برای نصبِ PWA، از همان صفحه «افزودن به صفحهٔ اصلی»/نصب را بزن؛ سرویس‌ورکر پوسته را پیش‌کش می‌کند و **دادهٔ زنده هرگز کش نمی‌شود**.

## معماری

| فایل | نقش |
|---|---|
| `app.py` | سرورِ `ThreadingHTTPServer` + API + کلِ رابطِ کاربری (HTML/CSS/JS درونِ همان فایل) |
| `smc_engine.py` | موتورِ تحلیل: سوینگ/ساختار/FVG/OB/لیکوئیدیتی/PD-OTE/سوئیپ/دیسپلیسمنت/کیل‌زون + واکشیِ داده + متراکم‌سازیِ تایم‌فریم |
| `confluence.py` | گریدرِ هم‌رایی، درجه‌بندی، مهرِ تأییدِ ورود، گیت‌های صداقتِ داده |
| `backtest.py` | بک‌تست روی همان موتورِ زنده (صفر منطقِ موازی)، بدونِ نگاه به آینده |
| `risk.py` | سایزِ پوزیشن، سقفِ ضررِ روزانه، هم‌بستگی/تمرکز (فاکتوری + عددی) |
| `smt.py` | واگراییِ SMT بین جفت‌های هم‌بسته |
| `backup.py` / `autobackup.py` | بستهٔ برون‌بری/درون‌بری + پشتیبانِ خودکارِ زمان‌بندی‌شده |
| `journal.py` (سازگارِ درون‌برنامه‌ای در `app.py`) | نوشتارگرِ ژورنالِ CSV |
| `fundamental.py` / `macro_context.py` | اخبارِ کلان و تقویمِ اقتصادی |
| `selfcheck.py` | نگهبانِ سلامتِ کد (سینتکس، قراردادِ کلیدها، مسیرها، توابعِ تعریف‌نشده، اتصالِ HTML/JS، قراردادِ PWA) + بازگردانیِ خودکار |
| `selfcheck_watcher.py` | آخرین خطِ دفاع: بازگشتِ خودکارِ `main` به آخرین کامیتِ سبزِ CI |
| `sw.js` / `manifest.webmanifest` | سرویس‌ورکر و مانیفستِ نصب (PWA) |

### چند قراردادِ عمدی

- **صفر وابستگی:** هیچ pip install ای لازم نیست؛ نه فریمیورک، نه DB، نه سرویسِ ابری.
- **بدونِ کلیدِ API:** بایننس (کریپتو)، Yahoo Finance (فارکس/فلزات/نفت)، و آینهٔ تقویمِ اقتصادی — همه بی‌کلید.
- **فقط لوکال:** سرور روی `127.0.0.1` می‌نشیند و عمداً لایهٔ احرازِ هویت ندارد، چون هرگز روی شبکه قرار نمی‌گیرد.
- **کندلِ بسته یا هیچ:** هیچ پنجرهٔ ناقصی خودش را جای کندلِ کامل جا نمی‌زند (هم در حذفِ کندلِ در حالِ تشکیل، هم در سقفِ «سبدِ کاملِ» تایم‌فریمِ بالا).
- **هم‌ترازیِ ۴ساعته با مرزهای UTC:** کندل‌های `4h` روی `t // 14400 * 14400` سبدبندی می‌شوند تا هندسهٔ چارت با چارتِ کارگزار یکی باشد.

## تست‌ها

هیچ چکی «سبزِ خاموش» قبول نمی‌شود: بیشترِ تست‌ها **جهش‌آزمایی** می‌کنند — یعنی یک خرابیِ عمدی می‌زنند و ادعا می‌کنند که تست **با نامِ همان مورد** قرمز می‌شود، و هم‌زمان جهش‌های بی‌گناه باید سبز بمانند.

```bash
python3 selfcheck.py            # نگهبانِ سلامت (کدِ سینتکس + قراردادها)
python3 selfcheck.py --guard    # بازگردانیِ خودکار از نسخهٔ سالم
python3 selfcheck.py --live     # چکِ سرورِ در حالِ اجرا

python3 engine_golden_test.py   # مقادیرِ عددیِ موتور روی سریِ ثابت (سوینگ/FVG/OB/PD-OTE/…)
python3 h4_alignment_test.py    # هم‌ترازیِ تجمیعِ ۴ساعته روی مرزهای UTC
python3 data_freshness_test.py  # کندلِ بسته، سنِ داده، باز/بسته‌ی بازار، ضدِ نگاه به آینده
python3 partial_candle_test.py  # موتور روی کندلِ ناقص سیگنال نمی‌سازد
python3 notify_mute_test.py     # تست‌ها روی دسکتاپِ تو نوتیف نمی‌فرستند (shimِ osascript)
python3 archive_actual_test.py  # نتیجه‌ی قطعیِ آرشیو: عددِ Actual + صعودی/نزولی (نه شرطی)
python3 button_alive_test.py    # کلیدِ بی‌واکنش نداریم: تورِ ایمنیِ فاندمنتال + واکنشِ دیدنیِ بروزرسانی
python3 dock_collapse_test.py   # بخشِ پشتیبان/انتقالِ داده جمع است، نه بلوکِ همیشه‌باز
python3 risk_test.py            # سایزِ پوزیشن، سقفِ ضرر، هم‌بستگی
python3 correlation_test.py     # ضرایبِ مرجع و تذکرِ تخلفِ کاربر
python3 smt_test.py             # واگراییِ SMT
python3 backup_test.py          # برون‌بری/درون‌بریِ دادهٔ کاربر
python3 autobackup_test.py      # پشتیبانِ خودکار و هرسِ امن
python3 journal_roundtrip_test.py
python3 pwa_test.py
python3 pwa_contract_test.py    # ← جهش‌آزماییِ قراردادِ PWA
python3 wiring_check_test.py    # ← جهش‌آزماییِ اتصالِ HTML/JS
python3 undefined_call_test.py  # ← جهش‌آزماییِ توابعِ تعریف‌نشده
python3 autorestart_test.py     # ری‌استارتِ خودکارِ کدِ کهنه
python3 selfcheck_watcher_test.py  # نگهبانِ بازگشتِ خودکار (سندباکسی)
```

CI روی گیت‌هاب (`.github/workflows/selfcheck.yml`) روی هر PR و روی هر پوش به `main` اجرا می‌شود و **۲۴ گامِ آزمون در ۶ لایه** را می‌گذراند: چکِ استاتیک و جهش‌آزمایی‌ها · اسموک‌تستِ سرورِ واقعی · تستِ مرورگریِ headless (رندر، سیم‌کشی، PWA و ارتقای ایمنِ نسخه) · و ده‌ها تستِ آفلاینِ عددی و رفت‌وبرگشتی.

سه لایه محافظت از `main`: هوکِ پیش‌کامیت روی همین دستگاه، ورک‌فلوی CI روی گیت‌هاب، و بازگردانیِ خودکارِ سرور/کد با `selfcheck --guard` و `selfcheck_watcher.py`.

## تنظیمات

همه با متغیرِ محیطی، همه اختیاری:

| متغیر | کار |
|---|---|
| `PIPFOUND_HOST` / `PIPFOUND_PORT` | میزبان و پورتِ سرور (پیش‌فرض `127.0.0.1:8787`) |
| `PIPFOUND_TOKEN` | توکنِ اختیاری برای اندپوینت‌های نوشتنی |
| `PIPFOUND_JOURNAL_CSV` / `PIPFOUND_JOURNAL_DIR` | مسیرِ فایل یا پوشهٔ ژورنال |
| `PIPFOUND_RISK_FILE` | محلِ تنظیماتِ ریسک |
| `PIPFOUND_AUTOBACKUP_FILE` / `PIPFOUND_BACKUP_DIR` / `PIPFOUND_AUTOBACKUP_STATE` | تنظیمات، پوشهٔ نسخه‌ها و حالتِ پشتیبانِ خودکار |
| `PIPFOUND_AUTORESTART` · `_INTERVAL` · `_SETTLE` · `_MAXWAIT` | رفتارِ ری‌استارتِ خودکارِ کدِ کهنه |
| `PIPFOUND_WATCH_*` | آستانه‌ها و حالتِ نگهبانِ بازگشتِ خودکار |
| `PIPFOUND_NOTIFY` | `0`/`off` ⇒ نوتیفیکیشنِ نیتیوِ مک خفه می‌شود (پیش‌فرض روشن؛ تست‌ها/CI با `0` بالا می‌آیند) |
| `PIPFOUND_SKIP_SELFCHECK` | رد کردنِ نگهبانِ سلامت هنگامِ کامیت (فقط اضطراری) |

## محدودیت‌ها و سلبِ مسئولیت

- این یک **ابزارِ پژوهشیِ شخصی** است، نه مشاورِ سرمایه‌گذاری و نه سیگنال‌فروشی. هیچ خروجی‌ای تضمینِ سود نیست و مسئولیتِ هر معامله با خودِ کاربر است.
- ضرایبِ هم‌بستگی، آستانه‌های موتور و جدولِ مشخصاتِ قراردادها **ثابت** و قابلِ بازبینی‌اند؛ محاسبهٔ زندهٔ آن‌ها یا ارسالِ خودکارِ سفارش به کارگزار انجام نمی‌شود.
- کیفیتِ تحلیل به کیفیتِ منبعِ داده گره خورد است: برای بازارهای سشندار (اندیکس‌ها، فلزات با وقفهٔ تسویهٔ روزانه) دادهِ ۱ساعتهٔ عمومی حفره دارد و قاعدهٔ «سبدِ کامل» عمداً یکی از شش کندلِ ۴ساعتهٔ روز را حذف می‌کند تا کندلِ ناقص جای کندلِ کامل ننشیند.
